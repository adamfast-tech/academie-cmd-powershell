### MISSION m3 ¦ « Le serveur de fichiers est plein » ¦ 3 ¦ Mesurer, trouver les gros fichiers, archiver sans rien casser.
@ticket INC-2063 ¦ P1 — Critique ¦ Tous services ¦ Supervision ¦ SRV-FICHIERS : volume D: à 97 %
>>> info ¦ Le contexte
L’alerte de supervision tombe : le volume de données du serveur de fichiers est presque plein. Si D: atteint 100 %, plus personne ne peut enregistrer ses documents.

Contraintes : **WinRM n’est pas activé** sur les serveurs. Tu travailles depuis ton poste, via les partages d’administration et CIM en DCOM.
>>> type ps ¦ Ouvre une session CIM en DCOM vers SRV-FICHIERS et range-la dans $s.
= $s = New-CimSession -ComputerName SRV-FICHIERS -SessionOption (New-CimSessionOption -Protocol Dcom) ;; $s=New-CimSession -ComputerName SRV-FICHIERS -SessionOption (New-CimSessionOption -Protocol Dcom) ;; $s = New-CimSession SRV-FICHIERS -SessionOption (New-CimSessionOption -Protocol Dcom)
hint: `$s = New-CimSession -ComputerName SRV-FICHIERS -SessionOption (New-CimSessionOption -Protocol Dcom)`
>>> fill ps ¦ Affiche l’espace libre de chaque disque du serveur, en Go.
```code ps
Get-CimInstance Win32_LogicalDisk -CimSession $s -Filter "DriveType=3" |
    Select-Object DeviceID, @{N='Libre (Go)'; E={ [math]::Round($_.___ / 1GB, 1) }}
```
= FreeSpace
~ Size ;; Free ;; Length ;; Capacity
? `FreeSpace` = espace libre en octets ; `Size` = capacité totale. `Length` est la taille d’un fichier, pas d’un disque.
>>> info ¦ Trouver où est la place
Via le partage d’administration `\\SRV-FICHIERS\D$`, on mesure chaque dossier de premier niveau :
```code ps
Get-ChildItem \\SRV-FICHIERS\D$\Partages -Directory | ForEach-Object {
    [PSCustomObject]@{
        Dossier = $_.Name
        Go      = [math]::Round((Get-ChildItem $_.FullName -Recurse -File -ErrorAction SilentlyContinue |
                    Measure-Object Length -Sum).Sum / 1GB, 1)
    }
} | Sort-Object Go -Descending
```
```out

Dossier       Go
-------       --
Marketing  412,6
Compta      88,3
RH          41,7
Direction   12,9
```
!it Le Marketing pèse 400 Go : vidéos de tournage de la nouvelle campagne. Les gros consommateurs d’espace sont presque toujours des médias, des archives .pst ou des sauvegardes oubliées.
>>> order ps ¦ Construis : les 10 plus gros fichiers du partage Marketing.
~ Get-ChildItem \\SRV-FICHIERS\D$\Partages\Marketing -Recurse -File ;; | ;; Sort-Object Length -Descending ;; | ;; Select-Object -First 10 FullName, @{N='Go';E={[math]::Round($_.Length/1GB,1)}}
x~ Format-Table ;; Measure-Object

>>> qcm ¦ Tu trouves 180 Go de fichiers `.mov` de 2024 dans « Marketing\Rushes ». Que fais-tu ?
+ Valider avec la responsable Marketing, puis déplacer vers l’archive avec robocopy
* Les supprimer immédiatement, ils sont vieux
* Les compresser sur place avec Compress-Archive
* Agrandir le disque sans prévenir personne
? On ne supprime jamais les données d’un service sans son accord. L’archivage libère la place en conservant les fichiers.
>>> info ¦ Archiver avec robocopy /MOV
```code cmd
robocopy "\\SRV-FICHIERS\D$\Partages\Marketing\Rushes" "\\SRV-ARCHIVE\Archives$\Marketing\Rushes" /E /MOV /MINAGE:365 /R:1 /W:1 /LOG:C:\Logs\archivage_marketing.log /TEE
```
```anatomy cmd
/E ¦ sw ¦ Tous les sous-dossiers, même vides.
/MOV ¦ sw ¦ **MOV**e files : supprime chaque fichier de la source **après** une copie réussie.
/MINAGE:365 ¦ sw ¦ **MIN**imum **AGE** : seulement les fichiers de plus de 365 jours.
/R:1 /W:1 ¦ sw ¦ 1 nouvelle tentative, 1 seconde d’attente (au lieu de 1 million et 30 s par défaut).
/LOG: ¦ sw ¦ Journal écrit dans un fichier…
/TEE ¦ sw ¦ …et affiché à l’écran en même temps.
```
!warn Fais un premier passage avec **`/L`** (**L**ist only) : robocopy affiche ce qu’il ferait sans rien déplacer.
>>> fill cmd ¦ Ajoute le commutateur qui simule l’opération.
```code cmd
robocopy D:\Partages\Marketing\Rushes \\SRV-ARCHIVE\Archives$\Marketing\Rushes /E /MOV /MINAGE:365 ___
```
= /L
~ /S ;; /MIR ;; /WhatIf ;; /TEST
? `/L` (**L**ist only) affiche ce qui serait déplacé sans rien toucher. `-WhatIf` est l’équivalent PowerShell, robocopy ne le connaît pas.

### MISSION m5 ¦ Inventaire du parc pour la direction ¦ 3 ¦ Modèle, numéro de série, mémoire et OS de chaque poste, dans Excel, sans WinRM.
@ticket REQ-3322 ¦ P3 — Normale ¦ Direction ¦ Sophie Martin ¦ Liste des PC avec modèle et âge pour le budget de renouvellement
>>> info ¦ Le script de l’équipe
L’équipe a déjà un script, `C:\Scripts\inventaire.ps1`. Tu vas le lire, le comprendre, puis le lancer.
```script ps C:\Scripts\inventaire.ps1
param(
    [string]$OU = "OU=Postes,OU=Ordinateurs,DC=contoso,DC=local",
    [string]$Sortie = "C:\Temp\inventaire_parc.csv"
)
$opt = New-CimSessionOption -Protocol Dcom
$resultats = foreach ($pc in Get-ADComputer -Filter 'Enabled -eq $true' -SearchBase $OU) {
    $nom = $pc.Name
    if (-not (Test-Connection -ComputerName $nom -Count 1 -Quiet)) {
        Write-Warning "$nom injoignable"
        [PSCustomObject]@{ Poste = $nom; Etat = 'Hors ligne'; Modele = ''; Serie = ''; RAM_Go = ''; OS = '' }
        continue
    }
    $s    = New-CimSession -ComputerName $nom -SessionOption $opt
    $cs   = Get-CimInstance Win32_ComputerSystem -CimSession $s
    $bios = Get-CimInstance Win32_BIOS -CimSession $s
    $os   = Get-CimInstance Win32_OperatingSystem -CimSession $s
    Remove-CimSession $s
    [PSCustomObject]@{
        Poste  = $nom
        Etat   = 'En ligne'
        Modele = $cs.Model
        Serie  = $bios.SerialNumber
        RAM_Go = [math]::Round($cs.TotalPhysicalMemory / 1GB)
        OS     = $os.Caption
    }
}
$resultats | Export-Csv -Path $Sortie -NoTypeInformation -Delimiter ';' -Encoding UTF8
```
>>> qcm ¦ Pourquoi le script utilise-t-il `New-CimSessionOption -Protocol Dcom` ?
+ Parce que WinRM n’est pas activé sur les postes : DCOM passe par RPC
* Parce que DCOM est plus récent que WinRM
* Pour chiffrer le fichier CSV
* Pour interroger Active Directory
? Sans cette option, `New-CimSession` tenterait WS-Man (WinRM, port 5985) et échouerait sur chaque poste.
>>> qcm ¦ À quoi sert `$resultats = foreach (…) { … }` ?
+ À récupérer dans une variable tous les objets produits par la boucle
* À compter les postes
* À ne garder que le dernier poste
* À rien, c’est une erreur
? Tout ce que la boucle **produit** (les [PSCustomObject]) est collecté dans `$resultats`, plus efficace que `+=` à chaque tour.
>>> qcm ¦ Que fait `continue` dans le bloc « injoignable » ?
+ Passe au poste suivant sans tenter la connexion CIM
* Arrête tout le script
* Relance le test de ping
* Réessaie le même poste
? Le poste hors ligne figure quand même dans le rapport (objet « Hors ligne »), puis on passe au suivant.
>>> fill ps ¦ Le script doit tourner sur un poste où la stratégie d’exécution est Restricted, sans la modifier. Complète la commande.
```code cmd
powershell.exe ___ Bypass -File C:\Scripts\inventaire.ps1
```
= -ExecutionPolicy
~ -Policy ;; -Scope ;; -NoProfile ;; /bypass
? La stratégie passée sur la ligne de commande ne vaut que pour ce processus : le réglage du poste reste inchangé.
>>> type ps ¦ Lance le script en lui indiquant d’écrire le résultat dans C:\Temp\parc.csv.
= C:\Scripts\inventaire.ps1 -Sortie C:\Temp\parc.csv ;; & C:\Scripts\inventaire.ps1 -Sortie C:\Temp\parc.csv ;; & 'C:\Scripts\inventaire.ps1' -Sortie C:\Temp\parc.csv ;; & "C:\Scripts\inventaire.ps1" -Sortie C:\Temp\parc.csv ;; C:\Scripts\inventaire.ps1 -Sortie 'C:\Temp\parc.csv' ;; C:\Scripts\inventaire.ps1 -Sortie "C:\Temp\parc.csv"
? Dans le Terminal du site, la stratégie est `Restricted` au départ : tu verras l’erreur, puis tu pourras lancer `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser` et réessayer.
>>> info ¦ Aller plus loin
Améliorations possibles, que tu sais maintenant écrire :
- ajouter la **date du BIOS** (`$bios.ReleaseDate`) pour estimer l’âge du poste ;
- ajouter l’**utilisateur connecté** (`$cs.UserName`) et l’espace disque (`Win32_LogicalDisk`) ;
- entourer la partie CIM d’un `try { } catch { }` avec `-ErrorAction Stop` : un pare-feu qui bloque WMI ne doit pas arrêter le script ;
- planifier le script chaque lundi (`schtasks /create … /sc weekly /d MON`).
