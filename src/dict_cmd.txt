@@ cmd cd ¦ Fichiers ¦ Affiche ou change le dossier courant. ¦ [C]hange [D]irectory
syn: cd [/d] [lecteur:][chemin]
syn: cd ..
/d ¦ [D]rive ¦ Change aussi de lecteur (sinon seul le dossier mémorisé de l’autre lecteur change).
ex: cd /d D:\Backup ¦ Aller sur D: et dans Backup en une fois.
ex: cd .. ¦ Remonter d’un niveau (`..` = dossier parent).
ex: cd \ ¦ Revenir à la racine du lecteur.
note: `chdir` est un synonyme. Sans argument, `cd` affiche le dossier courant.
see: `pushd`, `popd`, `Set-Location`

@@ cmd dir ¦ Fichiers ¦ Liste les fichiers et dossiers. ¦ [DIR]ectory
syn: dir [chemin][motif] [/a[:attr]] [/o[:tri]] [/s] [/b] [/w] [/p] [/q] [/t[:c|a|w]]
/a ¦ [A]ttributes ¦ Filtre par attributs : `h` caché, `s` système, `d` dossier, `r` lecture seule, `a` archive, `-` pour inverser. `/a` seul : tout.
/o ¦ [O]rder ¦ Tri : `n` nom, `s` taille (size), `d` date, `e` extension, `g` dossiers d’abord (group), `-` inverse.
/s ¦ [S]ubdirectories ¦ Parcourt tous les sous-dossiers.
/b ¦ [B]are ¦ Format brut : un nom par ligne (chemin complet avec /s).
/w ¦ [W]ide ¦ Affichage large en colonnes.
/p ¦ [P]ause ¦ Pause à chaque écran.
/q ¦ « [Q]ui possède ? » (pas d’abréviation officielle) ¦ Affiche le propriétaire de chaque fichier.
/t ¦ [T]ime field ¦ Quelle date afficher/trier : `c` création, `a` dernier accès, `w` écriture.
/l ¦ [L]owercase ¦ Noms en minuscules.
/4 ¦ — ¦ Années sur 4 chiffres.
ex: dir /a:h ¦ Seulement les éléments cachés.
ex: dir C:\Users\*.pst /s /b ¦ Trouver tous les .pst.
ex: dir C:\Data /o:-s ¦ Du plus gros au plus petit.
see: `Get-ChildItem`, `tree`, `where`

/a ¦ [A]SCII ¦ Caractères ASCII simples (pour copier dans un fichier texte).
ex: tree C:\Data /f ¦ Toute l’arborescence avec les fichiers.

@@ cmd del ¦ Fichiers ¦ Supprime des fichiers. ¦ [DEL]ete
syn: del [/p] [/f] [/s] [/q] [/a[:attr]] fichiers
/p ¦ [P]rompt ¦ Demande confirmation pour chaque fichier.
/f ¦ [F]orce ¦ Supprime aussi les fichiers en lecture seule.
/s ¦ [S]ubdirectories ¦ Supprime dans tous les sous-dossiers.
/q ¦ [Q]uiet ¦ Pas de confirmation pour les jokers globaux.

see: `Remove-Item`

@@ cmd copy ¦ Fichiers ¦ Copie un ou plusieurs fichiers. ¦ [COPY] : copier

/v ¦ [V]erify ¦ Vérifie l’écriture.

@@ cmd xcopy ¦ Fichiers ¦ Copie des arborescences (ancienne génération). ¦ e[X]tended [COPY]
syn: xcopy source destination [/s] [/e] [/h] [/y] [/i] [/d[:date]] [/c] [/k]
/s ¦ [S]ubdirectories ¦ Copie les sous-dossiers non vides.
/e ¦ [E]mpty ¦ Copie aussi les sous-dossiers vides (avec /s).
/h ¦ [H]idden ¦ Inclut les fichiers cachés et système.
/y ¦ [Y]es ¦ Écrase sans demander.
/i ¦ [I]s a directory ¦ Considère que la destination est un dossier.
/d ¦ [D]ate ¦ Seulement les fichiers plus récents (ou modifiés depuis la date).
/c ¦ [C]ontinue ¦ Continue malgré les erreurs.
/k ¦ [K]eep ¦ Conserve les attributs (lecture seule…).

@@ cmd robocopy ¦ Fichiers ¦ Copie robuste : reprise, miroir, journal, multithread. ¦ [ROBU]st file [COPY]
syn: robocopy source destination [fichiers] [options]
/s ¦ [S]ubdirectories ¦ Sous-dossiers non vides.
/e ¦ [E]mpty ¦ Tous les sous-dossiers, même vides.
/mir ¦ [MIR]ror ¦ Miroir : `/e` + supprime de la destination ce qui n’existe plus à la source. Attention aux suppressions.
/mov ¦ [MOV]e files ¦ Déplace les fichiers (supprime la source après copie).
/move ¦ [MOVE] ¦ Déplace fichiers et dossiers.
/z ¦ restartable mode ¦ Mode reprise : continue une copie interrompue (réseau instable).
/b ¦ [B]ackup mode ¦ Mode sauvegarde : contourne les droits NTFS (privilège requis).
/copy ¦ [COPY] flags ¦ Quoi copier : `D` données, `A` attributs, `T` dates, `S` sécurité, `O` propriétaire, `U` audit. Défaut : DAT.
/copyall ¦ [COPY ALL] ¦ Équivaut à `/copy:DATSOU` (avec les droits).
/r ¦ [R]etries ¦ Nombre de nouvelles tentatives (défaut : 1 million !). Ex. `/r:2`.
/w ¦ [W]ait ¦ Secondes entre deux tentatives (défaut : 30). Ex. `/w:5`.
/xf ¦ e[X]clude [F]iles ¦ Exclut des fichiers (`/xf *.tmp ~*`).
/xd ¦ e[X]clude [D]irectories ¦ Exclut des dossiers.
/minage ¦ [MIN]imum [AGE] ¦ Ignore les fichiers plus récents que N jours.
/maxage ¦ [MAX]imum [AGE] ¦ Ignore les fichiers plus vieux que N jours.
/l ¦ [L]ist only ¦ Simulation : liste sans rien copier.
/log ¦ [LOG] ¦ Écrit le journal dans un fichier (`/log+:` pour ajouter).
/tee ¦ [TEE] ¦ Journal à l’écran ET dans le fichier.
/np ¦ [N]o [P]rogress ¦ Pas de pourcentage (journal plus lisible).
/mt ¦ [M]ulti[T]hread ¦ Copie parallèle (`/mt:16`).
/xo ¦ e[X]clude [O]lder ¦ N’écrase pas un fichier plus récent à la destination.
ex: robocopy C:\Data D:\Backup /MIR /R:2 /W:5 /NP /LOG+:C:\Logs\backup.log ¦ Sauvegarde miroir avec journal.
ex: robocopy \\SRV-FICHIERS\Compta D:\Compta /E /Z /COPYALL /L ¦ Simulation d’une migration avec les droits.
note: Codes de retour : 0 rien à faire, 1 copie OK, 2 extras, 4 différences, 8 et plus = échec. Tester `if %ERRORLEVEL% GEQ 8`.
see: `xcopy`, `Copy-Item`

@@ cmd find ¦ Texte ¦ Cherche une chaîne exacte dans des fichiers ou une sortie. ¦ [FIND] : trouver

/i ¦ [I]gnore case ¦ Ignore majuscules/minuscules.

@@ cmd findstr ¦ Texte ¦ Cherche des chaînes ou des expressions régulières. ¦ [FIND] [STR]ing
syn: findstr [/i] [/s] [/n] [/v] [/b] [/e] [/r] [/c:"texte"] motifs [fichiers]
/i ¦ [I]gnore case ¦ Insensible à la casse.
/s ¦ [S]ubdirectories ¦ Cherche aussi dans les sous-dossiers.
/n ¦ [N]umber ¦ Numéros de ligne.
/v ¦ in[V]ert ¦ Lignes sans correspondance.
/b ¦ [B]eginning ¦ Le motif doit être en début de ligne.
/e ¦ [E]nd ¦ Le motif doit être en fin de ligne.
/r ¦ [R]egex ¦ Motifs = expressions régulières (par défaut pour les motifs simples).
/l ¦ [L]iteral ¦ Motifs pris littéralement.
/c: ¦ [C]hercher la chaîne exacte ¦ Phrase exacte, espaces compris. Répétable.
/m ¦ [M]atching files ¦ Affiche seulement le nom des fichiers qui correspondent.
ex: findstr /i "erreur echec" C:\Logs\*.log ¦ Lignes contenant erreur OU echec.
ex: systeminfo | findstr /b /c:"Nom du système" ¦ Phrase exacte en début de ligne.
ex: findstr /s /i /m "SRV-APP01" C:\Scripts\* ¦ Quels scripts mentionnent ce serveur ?
note: Plusieurs mots sans `/c:` = OU logique.
see: `find`, `Select-String`

@@ cmd icacls ¦ Fichiers ¦ Affiche ou modifie les permissions NTFS. ¦ [I]ntegrity [C]ontrol [ACL]s

/f ¦ [F]ile / [F]ields ¦ Lignes d’un fichier ou d’une commande, découpées : `tokens=`, `delims=`, `skip=`, `eol=`, `usebackq`.
/d ¦ [D]irectories ¦ Dossiers.
/r ¦ [R]ecursive ¦ Fichiers de tous les sous-dossiers.
ex: for /l %i in (1,1,254) do @ping -n 1 -w 200 192.168.10.%i | find "TTL" ¦ Balayer un réseau.
ex: for /f "skip=1 tokens=1,2 delims=;" %a in (C:\Data\nouveaux.csv) do @echo %b %a ¦ Lire un CSV.
note: Dans un .bat : `%%i` au lieu de `%i`. Modificateurs : `%~ni` nom, `%~xi` extension, `%~zi` taille, `%~ti` date, `%~fi` chemin complet, `%~dpi` dossier.

@@ cmd goto ¦ Scripts batch ¦ Saute à une étiquette. ¦ [GO] [TO]
syn: goto :étiquette | goto :eof
ex: if errorlevel 1 goto :erreur ¦ Gestion d’erreur.
note: `:eof` (End Of File) termine le script ou le sous-programme.

@@ cmd call ¦ Scripts batch ¦ Appelle un autre script ou un sous-programme, puis revient. ¦ [CALL] : appeler
syn: call script.bat [arguments] | call :étiquette [arguments]
ex: call :log "Début" ¦ Sous-programme avec argument (%~1).
note: Sans `call`, un .bat lancé depuis un autre ne rend jamais la main.

@@ cmd choice ¦ Scripts batch ¦ Demande à l’utilisateur d’appuyer sur une touche. ¦ [CHOICE] : choix
syn: choice [/c touches] [/n] [/t secondes /d défaut] [/m "message"]
/c ¦ [C]hoices ¦ Touches autorisées (défaut : ON).
/n ¦ [N]o display ¦ N’affiche pas la liste des touches.
/t ¦ [T]imeout ¦ Délai avant réponse par défaut.
/d ¦ [D]efault ¦ Réponse par défaut.
/m ¦ [M]essage ¦ Texte affiché.
/cs ¦ [C]ase [S]ensitive ¦ Respecte la casse.
ex: choice /c ONQ /m "Continuer" ¦ ERRORLEVEL = position de la touche (1, 2, 3).

@@ cmd timeout ¦ Scripts batch ¦ Attend un nombre de secondes. ¦ [TIMEOUT] : délai
syn: timeout /t secondes [/nobreak]
/t ¦ [T]ime ¦ Secondes (-1 = indéfiniment).
/nobreak ¦ [NO] [BREAK] ¦ Ignore les touches.
ex: timeout /t 5 /nobreak > nul ¦ Pause silencieuse de 5 s.

@@ cmd pushd ¦ Fichiers ¦ Mémorise le dossier courant et va ailleurs (même un partage). ¦ [PUSH] [D]irectory
syn: pushd chemin | popd
ex: pushd \\SRV-FICHIERS\Compta ¦ Mappe une lettre temporaire au partage UNC et y entre.
ex: popd ¦ Revient au dossier mémorisé (et libère la lettre temporaire).
note: `cd` refuse les chemins UNC ; `pushd` les accepte.

@@ cmd start ¦ Système ¦ Lance un programme, un fichier ou une URL dans une nouvelle fenêtre. ¦ [START] : démarrer
syn: start ["titre"] [/wait] [/min] [/max] [/d dossier] programme
/wait ¦ [WAIT] ¦ Attend la fin du programme.
/min ¦ [MIN]imized ¦ Fenêtre réduite.
/d ¦ [D]irectory ¦ Dossier de démarrage.
ex: start "" "C:\Temp\gpo.html" ¦ Ouvrir avec le programme associé. Le premier "" est le titre !
ex: start /wait msiexec /i C:\Tools\app.msi /qn ¦ Installation silencieuse en attendant la fin.

@@ cmd chcp ¦ Scripts batch ¦ Change la page de codes (encodage) de la console. ¦ [CH]ange [C]ode [P]age
syn: chcp [numéro]
ex: chcp 65001 > nul ¦ UTF-8 : accents corrects dans un script UTF-8.
note: 850 = OEM Europe de l’Ouest (défaut), 1252 = Windows Latin-1.

@@ cmd runas ¦ Domaine & sécurité ¦ Lance un programme sous un autre compte. ¦ [RUN] [AS] : exécuter en tant que
syn: runas /user:domaine\compte [/netonly] programme
/user ¦ [USER] ¦ Compte à utiliser.
/netonly ¦ [NET]work [ONLY] ¦ Identifiants utilisés seulement pour l’accès réseau.
ex: runas /user:CONTOSO\adm.it "mmc dsa.msc" ¦ Console AD avec un compte d’administration séparé.
